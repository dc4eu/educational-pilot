# End-User Survey Methodology: User Experience Monitoring Framework

## Executive Summary

This document outlines the comprehensive methodology employed for monitoring user experience (UX) during the DC4EU pilot testing activities. The methodology combines quantitative and qualitative feedback mechanisms designed to systematically collect, analyse, and implement improvements throughout the pilot phases. The approach prioritises identifying usability barriers, enhancing user trust, resolving technical issues, and implementing feature enhancements based on direct user feedback from multiple participant groups.

## Document Scope and Purpose

### Objective

The primary objective of this user experience monitoring methodology is to provide a structured framework for evaluating the effectiveness, usability, and acceptance of the EUDI Wallet implementation across diverse educational and professional contexts. This assessment enables data-driven decision making for tool refinement and enhancement.

### Target Participants

The methodology encompasses two distinct user categories:

**End Users (Primary Focus)**:
- Students at various educational levels (vocational, bachelor's, master's, PhD)
- Educational professionals and staff members
- Professional qualification candidates and holders

**Institutional Representatives**:
- Educational institution administrators
- VET (Vocational Education and Training) providers
- Qualification authorities and professional bodies

## Methodological Framework

### Research Approach

The methodology employs a mixed-methods approach combining quantitative metrics with qualitative feedback mechanisms. This dual approach ensures both statistical validity and contextual understanding of user experiences.

### Core Assessment Dimensions

The evaluation framework is structured around four critical dimensions:

#### 1. Ease of Use and Accessibility

This dimension measures how effortlessly users can navigate, understand, and utilise the toolset's features. The assessment recognises that even technically advanced solutions will face adoption barriers if users encounter frustration during basic interactions.

**Sub-dimensions examined**:
- **Installation Processes**: Measuring the complexity and success rates of initial setup
- **Interface Intuitiveness**: Assessing the clarity and logical flow of user interfaces
- **Accessibility Compliance**: Evaluating support for diverse user needs and assistive technologies

#### 2. Trust in the System

Trust represents a foundational element for any technology handling sensitive information, particularly in educational contexts where personal and academic data are involved. The trust assessment examines multiple facets:

**Privacy Assurance**: User confidence in data protection and handling mechanisms
**Institutional Credibility**: Perceived reliability and legitimacy of the technology platform

#### 3. Problem Identification and Classification

This dimension focuses on systematically documenting issues that impact user experience through structured reporting mechanisms:

**Installation Challenges**: Technical difficulties encountered during setup
**Comprehension Issues**: Problems related to understanding tool functionality
**Technical Malfunctions**: System errors and performance issues

#### 4. Improvement Suggestions

User-generated improvement ideas represent a valuable source of innovation that directly reflects actual usage patterns and needs:

**Interface Refinements**: Suggestions for enhanced user experience design
**Feature Requests**: Identification of missing functionality or desired enhancements

## Survey Instrument Design

### End-User Survey (S-EU) Structure

The end-user survey is designed to capture comprehensive feedback from students, learners, and professionals interacting with the EUDI Wallet during credential issuance and verification processes.

#### Demographic and Contextual Information
- Institutional affiliation identification
- Educational level classification (vocational, bachelor's, master's, PhD, professional, other)

#### User Experience Metrics
- **Net Promoter Score Assessment**: Likelihood to recommend the tool (1-10 scale)
- **Problem Identification**: Binary yes/no with open-ended specification
- **Improvement Suggestions**: Optional open-ended recommendations

#### Detailed Feature Evaluation
- **Feature Importance-Satisfaction Matrix**: Likert scale assessment (1-5) measuring both the importance of specific features and user satisfaction with current implementation
- **Installation Experience**: Five-point scale from unsuccessful installation to seamless completion
- **Technology Comprehension**: Assessment of user understanding of underlying technology

#### Trust and Privacy Assessment
- **Overall Trust Rating**: Five-point Likert scale measuring confidence in the tool
- **Trust Barrier Identification**: Specific elements reducing user confidence
- **Data Handling Confidence**: Assessment of perceived data security and privacy protection
- **Privacy Concern Specification**: Identification of specific areas of data handling concern

#### Training and Support Evaluation
- **Training Adequacy Assessment**: Evaluation of received training and educational materials
- **Support Area Identification**: Areas requiring better explanation or support
- **Interface Design Evaluation**: Assessment of user interface intuitiveness and visual appeal

### Institutional Survey (S-EI) Structure

The institutional survey captures feedback from higher education institutions, VET providers, and qualification authorities actively deploying EUDI Wallet-based services.

#### Institutional Context
- Institution identification and type classification
- Recommendation likelihood assessment for other institutions

#### Implementation Experience
- **Problem Documentation**: Issues encountered during installation and usage
- **Feature Assessment**: Institution-specific importance-satisfaction evaluation
- **Trust Evaluation**: Institutional confidence in the tool and workflow

#### Privacy and Data Governance
- **Data Handling Assessment**: Institutional confidence in personal data management
- **Privacy Risk Identification**: Specific areas of concern for data mishandling

#### Training and Documentation
- **Training Adequacy**: Assessment of received institutional training and documentation
- **Documentation Gaps**: Identification of areas requiring better explanation
- **Interface Usability**: Institutional assessment of user interface design

## Data Processing and Analytical Framework

### Analytical Categories

Results are analysed across multiple dimensions to facilitate targeted improvements:

#### User Group Segmentation
Survey responses are categorised by educational level (bachelor's, master's, PhD, vocational training, other) to enable group-specific analysis and targeted interventions.

#### Feature Priority Analysis
Feature development priorities are determined through a two-dimensional analysis matrix:
- **Feature Importance**: User-assessed significance of specific functionality
- **Feature Satisfaction**: User satisfaction with current implementation

This matrix enables direct prioritisation of development efforts based on user needs and satisfaction gaps.

#### Net Promoter Score (NPS) Calculation
The methodology employs the standard Net Promoter Score metric to assess user advocacy and likelihood of recommendation. This metric provides a benchmark for overall user satisfaction and tool adoption potential.

#### Issue Severity Classification
User-reported issues are systematically categorised and assigned severity scores. Each issue receives:
- **Issue Classification**: Category and severity assessment
- **Reporter Information**: User context and demographic data
- **Owner Assignment**: Responsibility allocation for resolution
- **Priority Rating**: Development and resolution priority

#### Trust Analysis Framework
Trust assessment visualisations measure user confidence across various dimensions using Likert scale responses. This analysis aims to identify root causes of distrust and provide actionable insights for improvement.

#### Training Effectiveness Evaluation
The methodology measures satisfaction with training provision, educational materials, and documentation to identify areas requiring enhancement. Additionally, technological understanding assessment helps refine educational materials and support resources.

## Feature Set Framework

### End-User Feature Assessment

The survey evaluates user experience across critical functionality areas:

**Credential Management Features**:
- Credential reception processes (PID, academic/professional credentials)
- Credential presentation workflows (VP generation)
- Credential status awareness (expiration, suspension, revocation)

**Usability Enhancement Features**:
- Integrated help and guidance systems
- Multi-language support capabilities
- Offline and low-connectivity resilience
- Accessibility technology compatibility

**Trust and Transparency Features**:
- Issuer information display clarity
- Verifier consent process transparency
- Credential verification event notifications
- Credential purpose explanation clarity

### Institutional Feature Assessment

The institutional survey evaluates organisational implementation experience:

**Administrative Features**:
- Issuer configuration simplicity
- Dashboard and logging capabilities
- System integration capabilities
- Credential template customisation

**Governance and Control Features**:
- Revocation and suspension management
- Data governance and compliance tools
- Audit and monitoring capabilities

All survey data collection and processing activities comply with established data protection frameworks:
- **Secure Data Transmission**: Encrypted data collection and storage
