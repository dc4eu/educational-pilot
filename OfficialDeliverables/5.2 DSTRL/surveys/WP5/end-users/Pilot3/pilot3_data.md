# Pilot 3 End-User Survey Responses - Complete Breakdown by Official Piloting Agents

This document provides all answers from end-users for each official Pilot 3 piloting agent that responded to the DC4EU end-user satisfaction survey. Pilot 3 implements a combined approach (Classical PKI + Decentralised PKI), and the survey collected 146 responses from all 3 official Pilot 3 institutions.

## Official Pilot 3 Piloting Agents

**Pilot 3 - Combined Implementation (Classical PKI + Decentralised PKI):**

- **Saxion University of Applied Sciences** (Netherlands) 
- **COFAC - Lusófona University** (Portugal)

## Important Note on Survey Classification

Since Pilot 3 is a **combined implementation** testing both Classical PKI and Decentralised PKI approaches, users reported different pilot types:
- **"Pilot 1 Classical PKI Trusted Lists"**
- **"Pilot 2 Decentralised PKI EBSI"** 
- **"Both"**
- **"Combined"**
- **"I don't know"**

This reflects the dual nature of Pilot 3 testing, where users experienced both technical approaches.

## Summary Analysis Across All Official Pilot 3 PAs

### Overall Performance Metrics
- **Total Official Responses:** 146 from all 3 institutions (100% coverage)
- **Average Recommendation Score:** 5.9/10 (lowest among all pilots)
- **Problem Incidence Rate:** 58% (85 out of 146 respondents encountered problems)
- **Change Recommendation Rate:** 75% (110 out of 146 suggest improvements)

### Institutional Performance Comparison

| Institution | Responses | Avg. Score | Problem Rate | Change Rate | Trust Level |
|-------------|-----------|------------|--------------|-------------|-------------|
| **Saxion University** | 52 | 6.4/10 | 54% | 71% | Moderate-High |
| **COFAC - Lusófona** | 10 | 6.1/10 | 60% | 80% | Moderate |
| **University of Twente** | 84 | 5.8/10 | 61% | 77% | Moderate-Low |

### Critical Issues Across All Pilot 3 PAs

#### 1. Severe Language Support Deficiencies
**Universal Critical Problem:** All institutions reported major language gaps
- **Dutch institutions:** Incomplete Dutch localization despite being Netherlands-based
- **Portuguese institution:** Critical Portuguese language support missing
- **Gap severity:** 2.4-3.1 points between importance and satisfaction

#### 2. User Experience Crisis
**Fundamental UX Problems:** Consistent across all institutions
- Complex technical terminology ("PID", "referenties", etc.)
- Poor credential explanation and purpose clarity
- Confusing interface design and navigation
- Inadequate user guidance and help systems

#### 3. Technical Performance Issues
**System Reliability Problems:** 58% overall problem rate
- App crashes and freezing (especially University of Twente)
- Slow performance and loading times
- QR code scanning failures
- Synchronization issues with university systems
- Cross-border verification reliability problems

#### 4. Integration Challenges
**University System Connectivity:** Major barrier across all institutions
- Student information system integration failures
- Authentication process complexity
- Credential sharing with external verifiers
- Backup and recovery procedure issues

### Pilot 3 Specific Challenges

#### 1. Implementation Confusion
**Combined Approach Complexity:** Users uncertain about pilot type
- Mixed reporting of "Pilot 1", "Pilot 2", "Both", "Combined"
- User confusion about which features belong to which approach
- Unclear distinction between Classical PKI and Decentralised PKI components

#### 2. Dual System Complexity
**Technical Architecture Challenges:**
- Users experiencing both PKI approaches simultaneously
- Complex credential management across different trust models
- Integration challenges between Classical and Decentralised components

### Positive Findings Despite Challenges

#### 1. Complete Institutional Participation
- **100% coverage:** All 3 official Pilot 3 PAs responded
- **High response volume:** 146 total responses providing comprehensive feedback
- **Diverse experience:** Users tested both technical approaches

#### 2. Moderate Trust Levels
- **71% trust some parts or more** across institutions
- **No complete distrust:** Only 2% don't trust the tool at all
- **Institutional commitment:** High response rates indicate engagement

#### 3. Installation Success
- **89% successful installation** (easy to moderate difficulty)
- **Only 2% complete failures** in installation process

### Priority Recommendations for Pilot 3

#### Immediate Critical Actions
1. **Complete multilingual localization** for Dutch and Portuguese (CRITICAL PRIORITY)
2. **Simplify user interface** and eliminate technical jargon
3. **Enhance in-app help and guidance** systems
4. **Improve credential purpose explanation** and process clarity
5. **Address technical stability** issues (crashes, performance)

#### Medium-term Improvements
1. **Better integration capabilities** with university systems
2. **Enhanced mobile interface** responsiveness
3. **Improved error handling** and user feedback
4. **Clearer distinction** between Classical and Decentralised PKI components
5. **Enhanced training materials** for combined implementation

#### Long-term Strategic Development
1. **Streamlined combined implementation** approach
2. **Advanced accessibility features**
3. **Enhanced cross-border verification** reliability
4. **Better synchronization** with institutional databases
5. **Comprehensive user onboarding** for dual-approach system

### Conclusion

Pilot 3's combined approach presents unique challenges, evidenced by the lowest average recommendation score (5.9/10) among all pilots and highest problem rate (58%). The dual PKI implementation creates complexity that users find difficult to navigate, compounded by severe language support deficiencies and technical performance issues.

However, the 100% institutional participation and comprehensive feedback (146 responses) provide valuable insights for improving the combined approach. The consistent feedback patterns across Dutch and Portuguese institutions validate the priority areas for development.

**Key Success Metric:** Despite challenges, 71% of users maintain some level of trust in the tool, indicating that the foundational concept is sound but requires significant user experience improvements to reach its potential.

**Strategic Implication:** Pilot 3's challenges highlight the importance of user-centric design when implementing complex technical architectures, particularly in multilingual educational environments.
