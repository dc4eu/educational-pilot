# DC4EU Educational Pilot - Official Deliverables

This repository contains the official deliverables produced under Work Package 5 (Education and Professional Qualifications) of the Digital Credentials for Europe (DC4EU) large-scale pilot project. These deliverables represent the comprehensive work conducted to integrate European Blockchain Services Infrastructure (EBSI) capabilities with the EUDI Wallet Reference Implementation, establishing a foundation for secure, interoperable digital credentials in European education.

## Overview

The DC4EU educational pilot demonstrates end-to-end implementation of EBSI-compliant verifiable credentials within the European digital identity ecosystem. Through systematic analysis, prototype development, and stakeholder feedback, these deliverables provide both theoretical frameworks and practical solutions for implementing digital credentials across European educational institutions and professional qualification bodies.

## Available Deliverables

### D5.1 - Business Blue Print (BBP)

**[→ View Documentation](./5.1%20BBP/README.md)**

A comprehensive framework for digital credential management across the European Union that establishes the foundation for trusted, interoperable, and privacy-preserving digital credentials supporting educational mobility and professional recognition throughout Europe. Built upon the European Digital Identity framework (eIDAS 2.0), the BBP addresses fundamental challenges facing educational institutions, students, and professionals in managing and verifying qualifications across borders whilst respecting institutional autonomy.

**Key highlights:**
- Comprehensive trust model and governance framework for credential operations
- Structured onboarding procedures for individuals and institutions
- Standardised approaches for digital credential lifecycle management
- Technical framework with detailed data model architecture and implementation guidance

### D5.2 - Deployment and Testing Scenarios Results Library (DSTRL)

**[→ View Documentation](./5.2%20DSTRL/README.md)**

A comprehensive repository documenting real-world implementation results, testing scenarios, and deployment experiences from the DC4EU project's piloting activities across European educational institutions. The DSTRL serves as the authoritative collection of practical implementation evidence, lessons learned, and operational insights from deploying digital credential systems across diverse institutional and national contexts using three distinct technical approaches.

**Key highlights:**
- Implementation evidence from 36+ educational institutions across 14 European countries
- Comprehensive results documentation covering Classical PKI, Decentralised PKI, and Combined implementation approaches
- Cross-border verification evidence demonstrating international credential recognition capabilities
- Performance analysis and comparative assessment of different deployment models
- Evidence-based recommendations for future implementations and policy development

### D5.3 - The Initiatives Mapping and Alignment Checklist (IMAC)

**[→ View Documentation](./5.3%20The%20Initiatives%20Mapping%20and%20Alignment%20Checklist/README.md)**

A comprehensive framework document that serves as a unified guide for implementing digital credentials within the European Union's education and professional qualification framework. The IMAC combines theoretical governance principles with practical implementation guidance, addressing privacy-by-design principles, selective disclosure policies, and cross-border interoperability. This deliverable provides actionable recommendations and readiness checklists to support stakeholders in building secure, user-centric digital public infrastructure for education across Europe.

**Key highlights:**
- Comprehensive governance framework respecting subsidiarity whilst enabling European coordination
- Legal and regulatory framework aligned with eIDAS 2.0 compliance
- Technical interoperability guidelines supporting both classical PKI and decentralised PKI approaches
- Implementation considerations for stakeholder onboarding and security measures

### D5.4 - Tooling Evaluation Report

**[→ View Documentation](./5.4%20Tooling%20Evaluation%20Report/dc4eu_d5.4_summary.md)**

A systematic technical assessment of available tools and libraries required to integrate EBSI capabilities into the EUDI Wallet Reference Implementation. This evaluation provides evidence-based tooling selection through comprehensive analysis of EBSI Hub Libraries and Walt.id Android SDK, establishing the technical foundation for subsequent prototype development. The report addresses specific architectural constraints imposed by existing RI components and proposes hybrid integration approaches.

**Key highlights:**
- Comprehensive evaluation of EBSI Hub Libraries and Walt.id Android SDK
- Architectural recommendations for RI Issuer, RI Wallet, and RI Verifier integration
- Risk mitigation strategies for identified implementation challenges
- Pragmatic implementation plan balancing technical ideals with practical constraints

### D5.5 - Initial EBSI Integration Prototype

**[→ View Documentation](./5.5%20Initial%20EBSI%20Integration%20Prototype/dc4eu_d5.5_summary.md)**

The working prototype implementation that extends all three EUDI Wallet Reference Implementation components to support EBSI-compliant verifiable credentials. This deliverable demonstrates end-to-end credential workflows using real DIDs onboarded into the EBSI Pilot Registry, maintaining compatibility with original RI architecture whilst enabling full EBSI functionality through a dedicated microservice approach.

**Key highlights:**
- Complete enhancement of EUDI Issuer, Android Wallet, and Verifier components
- EBSI-Agent microservice providing technology-agnostic access to EBSI Hub Libraries
- Support for DID management, credential issuance, and verification operations
- Seamless integration preserving existing EUDI Wallet functionality

### D5.6 - Feedback and Refinement Report

**[→ View Documentation](./5.6%20Feedback%20and%20Refinement%20Report/dc4eu_d5.6_summary.md)**

The culminating report documenting the complete journey from conceptual planning to practical implementation of experimental EBSI support within the EUDI Wallet Reference Implementation. This comprehensive analysis provides detailed feedback on integration challenges, technical refinements, and the operational prototype demonstrating end-to-end EBSI-compliant credential workflows using real infrastructure deployed on production-ready server environments.

**Key highlights:**
- Documentation of implementation challenges and pragmatic architectural adaptations
- Real-world EBSI integration with registered DIDs in EBSI Pilot Trust Registry
- Complete demonstration of educational credential workflows from issuance through verification
- Future development pathways for native integration and interoperability expansion

## Project Context

These deliverables support the broader DC4EU initiative to establish secure, privacy-preserving digital credential infrastructure across Europe. The educational pilot specifically addresses the unique requirements of academic mobility, institutional autonomy, and cross-border recognition of qualifications within the European Higher Education Area (EHEA) framework.
